# Sandeep Singh Portfolio

Static personal portfolio and resume site for Sandeep Singh, a Full Stack .NET Developer based in Mumbai, India.

## Files

- `index.html` - Main portfolio page.
- `style.css` - Shared portfolio styling.
- `script.js` - Scroll highlighting, reveal animations, smooth scrolling, cursor glow, and typed role text.
- `resume.html` - Print-friendly HTML resume.
- `Resume_Sandeep.pdf` - Downloadable resume linked from the site.
- `favicon.svg` - Site icon.

## Run Locally

Open `index.html` directly in a browser.

For a local server preview, run:

```powershell
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deploy

This project can be deployed to any static host, including GitHub Pages, Netlify, Vercel, or Cloudflare Pages. No build command is required.

## Maintenance Notes

- Update project card links when dedicated repositories or live demos are available.
- Keep `index.html`, `resume.html`, and `Resume_Sandeep.pdf` aligned when experience, project names, or contact details change.
- If the public phone number should not be indexed, remove the `tel:` link from `index.html` and keep contact through email or the resume only.
