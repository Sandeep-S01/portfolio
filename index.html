Velt Semantic Search — vector-embedded document retrieval

Problem. Traditional lexical keyword search fails to find conceptual matches when documentation uses synonyms, phrasing variations, or differing architectural terminology.

Approach. Built a Python backend with FastAPI that ingests unstructured technical documents, generates vector embeddings, and indexes them into ChromaDB. Coupled with a responsive Vite client providing live cosine similarity ranking.

Result. Deployed live on Vercel with instant query evaluation, proving practical systems integration of vector stores and modern semantic search pipelines.

  • FastAPI
  • ChromaDB
  • Vite
  • Python
  • Vector Search
